# QR Studio

Статический генератор скруглённых QR-кодов. Одиночная генерация и список до 100 ссылок, прозрачные SVG и PNG без полей и рамки, ZIP-архив для списка. Введённые ссылки и созданные коды сохраняются при переключении режимов. Все ссылки обрабатываются в браузере, без сетевых запросов.

Запуск: `npm start`, затем http://127.0.0.1:4173/.

Проверка: `npm ci`, затем `npm test`. Проверяется считывание экспортированных SVG независимым декодером, прозрачность, UTF-8, валидация ссылок и ZIP-архив.

Сайт находится в `dist/` и не требует сборки. Сторонние библиотеки включены локально: qrcode-generator 2.0.4 (MIT), fflate 0.8.2 (MIT). Шрифт Onest включён локально (SIL Open Font License). Зависимости npm нужны только для проверок.

Экспорт не содержит защитных полей. При размещении оставляйте вокруг кода светлое свободное поле не менее четырёх модулей.
